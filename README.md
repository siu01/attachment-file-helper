# 添付ファイルかんたん操作

添付ファイルやファイルリンクを「新しいタブで開く」操作なしで扱うための Chrome 拡張機能です。

## できること

- ファイルリンクを右クリックして、現在のタブで開く
- ファイルリンクを右クリックして、新しいタブで開く
- ファイルリンクを右クリックして、直接保存する
- 拡張機能のポップアップで、現在のページ内の添付ファイル候補を一覧表示する
- 一覧から「開く」「新しいタブ」「保存」を1クリックで実行する
- 複数の添付ファイルを、ページ名のフォルダにまとめて保存する
- Google Classroom のページ内検索で古い投稿・課題を探す
- Google Classroom の課題・投稿ページをローカル保存して後から開く
- PDF、画像、動画、音声、Office ファイル、CSV、ZIP などを自動判定する
- リンクだけでなく、画像・動画・音声を右クリックして操作する
- 右クリックで選択した URL 文字列も操作する

## Chrome への読み込み

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. このリポジトリのフォルダを選ぶ

コードを変更した場合は、拡張機能管理画面の更新ボタンを押してください。

ポップアップで複数の添付ファイルが見つかった場合は、保存先フォルダ名を確認して「まとめて保存」を押してください。Chrome の既定の Downloads フォルダ内に、`添付ファイルかんたん操作/<フォルダ名>/` として保存されます。

## 制限事項

サイト独自の JavaScript ボタンで、URL が HTML のリンクやメディア要素として公開されていない場合は自動検出できません。その場合は、サイトが実際に生成したダウンロード URL を選択して右クリックするか、通常のサイト側のダウンロードボタンを利用してください。

認証が必要なファイルは、Chrome のダウンロード API 経由で現在のブラウザセッションの Cookie を利用します。ただし、POST リクエスト、短時間で期限切れになる URL、Referer や独自ヘッダーを必須とするサイトでは、サイト側のダウンロード操作が必要になることがあります。

## 開発

```sh
npm test
```

外部ライブラリは使っていません。Chrome の Manifest V3 と標準 API だけで動作します。

## Google Classroom の不便さへの対応

Google Classroom では、投稿や通知が増えると過去の課題・資料を探しにくいこと、添付ファイルを開いてから保存する操作が多いこと、課題ページを後から見つけにくいことが利用者から指摘されています。この拡張機能では、現在開いている Classroom ページを対象に、ページ内検索、課題・投稿のローカル保存、添付ファイルの一覧化・個別保存・フォルダ一括保存を提供します。

Classroom の全クラス横断の締切一覧、提出状況、成績集計、通知統合は、Google Classroom API と Google アカウント認証が必要になるため、現バージョンでは扱いません。学校アカウントのデータを拡張機能の外部サーバーへ送信しない方針です。
